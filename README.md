# Blindspot

**The blind prediction market.** On Polymarket everyone sees every bet, so whales move the odds and everyone else copies them.
On Blindspot your side stays sealed with post-quantum encryption (ML-KEM-1024) until the market closes — you can see *how much* has been bet, never *which way*.

Built on [QoreChain](https://qorechain.io) (testnet `qorechain-diana`, EVM chain id 9800).
